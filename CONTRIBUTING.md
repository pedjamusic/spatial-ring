# Contributions & Collaboration

Thank you for your interest in this project!

### Project Status: Personal Learning Lab

This repository exists primarily as a space for me to practice my (and my friends Agent AI) coding skills and document my learning progress. Because this is a personal educational journey, **I am not accepting Pull Requests or external contributions at this time.**

### Why?

- **Skill Building:** I want to solve problems and fix bugs myself to ensure I'm fully grasping the concepts.
- **Capacity:** As I am still learning, I don't have the bandwidth to properly review, test, or discuss external code changes.

### Can I still use this code?

**Absolutely!** You are more than welcome to:

- **Fork** the repository for your own use.
- **Clone** the code to study how I've approached specific problems.
- **Reference** the logic in your own projects (subject to the license).

### If you find a bug...

While I appreciate the eagle eye, please don't open an Issue or Pull Request. I am working through the code at my own pace and will likely discover and tackle those bugs as part of my learning process.

_Thank you for respecting this boundary while I grow my skills!_
